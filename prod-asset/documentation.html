Project Overview

SF Youth Futsal | Elite Training & Academy adalah aplikasi berbasis landing-page dinamis dan sistem reservasi interaktif yang dirancang khusus untuk atlet muda berbakat dalam rentang usia 5 hingga 18 tahun (U5 - U18).

Aplikasi ini dirancang untuk memberikan pengalaman digital kelas dunia dengan visual modern layaknya klub olahraga profesional mancanegara. Dilengkapi animasi transisi super halus (60FPS), navigasi presisi, widget interaktif, formulir registrasi multi-step, serta panel drawer monitoring data pemesanan atau jadwal yang divalidasi dan disimpan di sisi klien secara instan.

Teknologi Utama yang Digunakan

React 18 UIdesigns & State
TypeScript Type Safety & Enums
Tailwind CSS Utility-First Engine
Framer Motion Smooth Animations
2

Aplikasi Website Sections (Modul UI)

Website ini terbagi ke dalam beberapa layout section dan komponen modular yang saling terisolasi dengan baik:

Header & Navbar Component

Menampilkan brand logo, tautan navigasi anchor-scrolling, status penghitung keranjang reservasi aktif secara berkelanjutan, dan tombol pemesanan instan.

Hero Section

Bagian pembuka dengan visual imersif berupa background berkualitas tinggi, judul megah menggunakan font olahraga Space Grotesk, serta lencana keunggulan (Awards, Rating Bintang) untuk membangun impresi profesional terbaik bagi calon pelanggan.

About Academy Section

Mencakup informasi terperinci mengenai filosofi futsal modern, visi jangka panjang, pencapaian tim kepelatihan bersertifikat, dan galeri interaktif program pembinaan atlet muda dari dasar hingga kelompok elit.

Futsal Camps & Tournaments Section

Bagian grid interaktif yang menyajikan program musiman seperti Summer Camps atau kompetisi antar akademi lengkap dengan lokasi spesifik, rentang usia, slot tersisa, dan tombol pendaftaran langsung.

Elite Training Packages Section

Daftar skema langganan latihan rutin lengkap dengan rincian biaya, jadwal pertemuan latihan per minggu, rasio pelatih berlisensi dengan murid, dan opsi pendaftaran instan.

Parent reviews / Testimonials Section

Dipercantik dengan sistem carousel atau penataan asimetris bento, menyajikan umpan balik asli dari orang tua siswa dan cerita kesuksesan alumni pelatihan akademi.

Contact Us Section

Formulir feedback pengguna yang terstruktur dengan detail alamat olahraga, koordinat lokasi latihan, sosial media resmi akademi, serta jam buka layanan harian.

BookingModal (Modals)

Pop-up interaktif multi-step dengan transisi halus dari library Framer Motion yang membimbing pengguna mengisi data pendaftaran, opsi kategori slot latihan/kamp, hari pelaksanaan, nama anak didik, dan pengisian catatan tambahan.

MyBookingsDrawer (Drawers)

Laci samping geser kanan (smooth sliding drawer) untuk memantau, memeriksa ulang, menetapkan status konfirmasi, atau membatalkan reservasi pendaftaran aktif yang telah tersimpan di localStorage perangkat pengguna.

Project Setup (Langkah Dasar Awal)

Berikut adalah daftar persiapan dan langkah instalasi untuk menjalankan aplikasi ini dari awal (scratch) secara lokal di lokal workstation pengembang:

Persyaratan Sistem sebelum Mulai (Prerequisites)

  • Node.js: Disarankan Node LTS versi 18.x atau yang lebih baru (v20+ direkomendasikan).
  • NPM / PNPM / Yarn: Node Package Manager bawaan minimal versi 9+ yang andal.
  • Penyunting Kode (Editor): Visual Studio Code yang dilengkapi ekstensi Tailwind CSS, ESLint, dan Prettier.

Langkah Setup Menit-demi-Menit

# 1. Ekstrak / Clone repositori proyek akademi futsal ini

git clone https://github.com/username/sf-youth-futsal.git

cd sf-youth-futsal

# 2. Lakukan instalasi seluruh library & modul ketergantungan (dependencies)

npm install

# 3. Jalankan server lokal untuk mode pengembangan (Development Mode)

npm run dev

Jika server pengembangan berjalan dengan sukses, Anda dapat membuka halaman demonstrasi live di peramban (browser) Anda pada alamat port lokal: http://localhost:3000.

Bagaimana Cara Mengedit Website Ini?

Panduan praktis untuk melakukan kustomisasi data, mengubah dekorasi visual, mengubah asset atau menyisipkan konten baru:

Ubah Konten Teks, Program Camp, dan Pilihan Paket Latihan

Seluruh data statis, seperti detail paket Futsal Camp dan Training Package didefinisikan secara dinamis menggunakan struktur data pada file utama src/App.tsx. Cari variabel array tersebut (misalnya INITIAL_CAMPS dan INITIAL_PACKAGES) untuk mengedit judul program, pelatih, nominal harga, lokasi latihan, maupun kuota slot terdaftar.

Ubah Icon & Grafik SVG

Situs ini memakai perpustakaan Lucide React sebagai penyedia icon bawaan. Jika Anda ingin mengganti icon pada tombol atau badge, Anda dapat mengimpor icon yang sesuai dari "lucide-react" pada header file komponen Anda, lalu menyisipkannya menggunakan JSX standar (misal: <Trophy className="w-5 h-5" />).

Sesuaikan Struktur Validasi Pendaftaran (Form Input)

Untuk mengedit field input, mengubah maksimal usia siswa futsal, atau menetapkan batasan jadwal hari pada sistem pendaftaran, Anda dapat menyunting file formulir di src/components/modals/BookingModal.tsx. Gunakan skema validasi React State untuk menambah atau mengurangi field dropship.

Langkah Deploy ke Server Production

Ketika pengembangan fitur dirasa matang dan siap dipublikasikan secara global untuk publik, jalankan instruksi optimasi berikut:

1. Jalankan Perintah Kompilasi Berkas (Optimization Build)

Jalankan perintah berikut pada terminal root proyek untuk memangkas ukuran kode dan aset guna meningkatkan waktu muat halaman secara instan di peramban:

npm run build

Perintah ini akan memproses file TypeScript, memangkas CSS Tailwind yang tidak terpakai (tree-shaking), lalu mengumpulkan berkas akhir yang super ringan ke dalam direktori keluaran statis bernama dist/.

2. Unggah Folder Statis "dist/" ke Platform Hosting

Anda dapat meluncurkan folder dist/ ke berbagai penyedia hosting modern seperti:

  • Vercel / Netlify: Sangat disarankan karena otomatisasi Git yang mudah. Cukup kaitkan repositori ini ke dasbor Vercel/Netlify Anda untuk proses deploy instan setiap ada push perubahan.
  • Google Cloud Run / VPS: Jika aplikasi Anda dijalankan dalam container Docker, Anda dapat memanfaatkan script pembantu dan server CJS bawaan yang ada di dist/server.cjs yang menyajikan static assets menggunakan engine Express.
