Project Overview

SF Youth Futsal | Elite Training & Academy is a dynamic landing page application and an interactive reservation system specifically designed for talented young athletes aged 5 to 18 (U5 - U18).

This application is designed to deliver a world-class digital experience with modern visuals, akin to professional sports clubs abroad. It features super-smooth transition animations (60FPS), precise navigation, interactive widgets, a multi-step registration form, and a drawer panel to monitor booking or schedule data that is instantly validated and saved client-side.

Key Technologies Used

React 19 UI Design & State
TypeScript Type Safety & Enums
Tailwind CSS Utility-First Engine
Framer Motion Smooth Animations
RHF & Zod Form Validation

Website Application Sections (UI Modules)

This website is divided into several layout sections and modular components that are well isolated from each other:

Header & Navbar Component

Displays the brand logo, anchor-scrolling navigation links, active reservation cart count updates, and an instant booking button.

Hero Section

Full-screen opening section with an autoplaying local video background (assets/football.mp4) enhanced with a Framer Motion entrance animation. Overlaid with a grand title using the sports-themed font Space Grotesk, a live admissions badge, and a prominent BOOK NOW call-to-action. The video uses a static image poster fallback and handles browser autoplay restrictions gracefully.

About Academy Section

Includes detailed information on modern futsal philosophy, long-term vision, achievements of the certified coaching staff, and an interactive gallery showing the development program for young athletes from grassroots to elite levels.

Futsal Camps & Tournaments Section

An interactive grid presenting seasonal programs like Summer Camps or inter-academy competitions, complete with specific locations, age ranges, remaining slots, and direct registration buttons.

Elite Training Packages Section

A list of regular training subscription schemes complete with cost breakdowns, weekly training session schedules, licensed coach-to-student ratio, and instant registration options.

Parent reviews / Testimonials Section

Enhanced with a carousel system or bento layout, presenting authentic feedback from parents and success stories from academy graduates.

Contact Us Section

A parallax-background contact section with a right-aligned white card showing the academy's email, phone, address, and social media links. Tapping "Contact Us" opens an inline ModalBase-powered popup form (name, email, phone, message) with a success animation on submit.

BookingModal (Modals)

An interactive multi-step pop-up built on top of ModalBase with smooth Framer Motion transitions that guide users through choosing a camp/training category, selecting dates, entering student names, and additional notes. Uses React Hook Form + Zod for type-safe validation.

MyBookingsDrawer (Drawers)

A smooth side drawer sliding from the right to monitor, review, or cancel active registrations stored in the user device's localStorage. All destructive actions (cancellations) are confirmed through the custom ConfirmModal component instead of native browser confirm() dialogs, ensuring a consistent on-brand UX.

ModalBase & ConfirmModal (Shared Modal System)

ModalBase is a reusable modal shell providing a consistent layout — animated backdrop, scroll-lock, close button, and optional tagline/title/description header. Both the Contact form popup and the BookingModal use it as their base. ConfirmModal is a lightweight dialog built on ModalBase designed specifically to replace all native confirm() calls with a styled, accessible alternative.

Project Setup (Basic Steps)

Here is the list of prerequisites and installation steps to run this application from scratch locally on your developer workstation:

System Prerequisites

  • Node.js: Recommended Node LTS version 18.x or newer (v20+ is recommended).
  • NPM / PNPM / Yarn: Default Node Package Manager version 9+ (or reliable equivalent).
  • Code Editor: Visual Studio Code equipped with Tailwind CSS, ESLint, and Prettier extensions.

Step-by-Step Setup

# 1. Extract the project ZIP file and navigate to the directory

cd football-academy-landing

# 2. Install all library & module dependencies

npm install

# 3. Start local development server

npm run dev

If the development server runs successfully, you can open the live demo page in your browser at the local port address: http://localhost:3000.

How to Edit This Website?

A practical guide to customize data, change visual styles, update assets, or insert new content:

Change Text Content, Camp Programs, and Training Packages

All static data, such as details of the Futsal Camp, Training Packages, and Testimonials are dynamically defined using data structures in the file src/data.ts. Search for those array variables (e.g., CAMPS_DATA, TRAININGS_DATA, and TESTIMONIALS_DATA) to modify program titles, coaches, pricing, training locations, slot quotas, or student testimonials.

Modify Icons & SVG Graphics

This site uses the Lucide React library for default icons. If you want to change an icon on a button or badge, you can import the appropriate icon from "lucide-react" at the top of your component file, and then insert it using standard JSX (e.g., <Trophy className="w-5 h-5" />).

Adjust Registration Validation Structure (Form Inputs)

To edit input fields, change validation ranges (such as student age group limits), or configure registration requirements, edit the form file at src/components/modals/BookingModal.tsx. The form is built using React Hook Form and Zod. You can customize fields and constraints simply by modifying the bookingSchema object. Note that the custom inputs inside src/components/form/ are configured with React.forwardRef to seamlessly register with the form.

Customize Branding Colors & Fonts (Tailwind CSS v4)

This project is built using Tailwind CSS v4.0, which deprecates the old tailwind.config.js file. All branding variables are configured directly inside the CSS stylesheet at src/index.css under the @theme directive. You can modify custom variables like --color-brand-blue, --color-brand-orange, or --font-display to instantaneously change the theme globally.

Modify Logo & Identity

The brand logo image is stored as assets/logo.png and is referenced by the src/components/Logo.tsx component (used in the Navbar) and directly via a relative path in the sidebar of this documentation file. To swap the logo, replace assets/logo.png with your own image file (keep the same filename, or update the import path in both places).

Replace Hero Background Video

The hero section uses a local video for its immersive fullscreen background. The video file is located at assets/football.mp4 and imported at the top of src/components/sections/Hero.tsx. To change the video, replace the football.mp4 file with your own video (H.264 MP4 is recommended for broadest browser support). The component already handles autoplay resumption on tab visibility change and suppresses browser autoplay restriction errors gracefully.

Edit the Site Footer

The footer is extracted into a standalone component at src/components/Footer.tsx. It contains the academy's brand tagline, quick navigation links, session info, and the copyright bar. Edit this file to update footer text, add social media links, or adjust the column layout.

Add or Customize Confirmation Dialogs

All destructive confirmations (e.g., cancelling a booking) use the custom src/components/modals/ConfirmModal.tsx component instead of the browser's native confirm(). To trigger a new confirm dialog, import ConfirmModal, manage its isOpen state locally, and pass the onConfirm callback. Set isDanger={true} to render the confirm button in red for irreversible actions.

Connect Forms to a Backend or Email API (For Marketplace Buyers)

By default, all booking submissions are stored locally on the client's web browser using localStorage, and the Contact form displays a success toast. For a live production website, you can easily connect these forms to dynamic backend API services or email microservices:

  • Contact Form: Open src/components/sections/ContactSection.tsx, look for the handleSubmit function, and integrate serverless form handlers like Formspree, Web3Forms, or EmailJS.
  • Booking Form: Open src/components/modals/BookingModal.tsx, locate the onSubmit function, and replace the localStorage push operation with a standard fetch() or axios.post() request sending the payload to your Node/Express/PHP server or Database webhook.

Steps to Deploy to Production Server

Once features are ready and ready to be published globally for the public, execute the following optimization steps:

1. Run the Build Command (Optimization Build)

Run the following command in the project's root terminal to reduce file size and assets, instantly improving page load times in browsers:

npm run build

This command compiles TypeScript files, tree-shakes unused Tailwind CSS utilities, and bundles lightweight assets into a static output directory named dist/.

2. Upload the Static "dist/" Folder to a Hosting Platform

You can deploy the dist/ folder to various modern hosting providers, such as:

  • Vercel / Netlify: Highly recommended due to easy Git automation. Just link this repository to your Vercel or Netlify dashboard for instant deployment on every push/merge.
  • Google Cloud Run / VPS: If your app is containerized via Docker, you can leverage the built-in helper script and CJS server in dist/server.cjs which serves static assets using the Express engine.
